# Python Day 151 – API Response Analyzer

## Description
A Python application that analyzes JSON API response data and generates a summary report.

## Features
- Reads JSON data.
- Counts total and active users.
- Calculates average user age.
- Groups users by department.
- Generates a JSON analysis report.
- Handles invalid or missing files.

## Files
- `api_analyzer.py` – Main Python program.
- `users.json` – Sample API response.
- `analysis_report.json` – Generated analysis.

## How to Run
```bash
python api_analyzer.py
```

## Concepts Used
- JSON Module
- Dictionaries and Lists
- Counter
- File Handling
- Exception Handling
- Data Analysis
